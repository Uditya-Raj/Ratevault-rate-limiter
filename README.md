# RateVault 🚦 API Rate Limiting Microservice

RateVault is a production-ready rate limiting microservice built with Spring Boot and Redis.  
It supports token bucket algorithm and dynamic plans for API usage control.

## ✅ Features
- JWT-based user filtering
- Redis-backed token bucket
- Docker support
- Plan-based limits

## 📦 Stack
Spring Boot, Redis, JWT, Docker
